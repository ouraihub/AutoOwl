# 安全审查清单

| 类别 | 检查项 | 状态 |
|---|---|---|
| capability | 未启用 shell 通配权限 | 待验证 |
| capability | fs 只允许用户选择的下载目录 | 待验证 |
| command | 所有输入有 DTO 校验 | 部分完成 |
| command | 管理 command 不被用户页面直接调用 | 部分完成 |
| credentials | Cookie 不进入前端持久化 | 部分完成 |
| credentials | Cookie 不写普通日志和错误 details | 部分完成 |
| filesystem | 下载路径拒绝绝对路径和 `..` | 部分完成 |
| filesystem | 目标文件使用临时文件和原子移动 | 部分完成 |
| process | FFmpeg 参数由 Rust 固定生成 | 待验证 |
| network | 超时、限流和资源过期有稳定错误码 | 部分完成 |
| logging | 日志不包含密码、Cookie 和完整敏感 URL | 部分完成 |
| data | 应用只读写自己的应用数据目录，不读取其它程序的数据库和下载目录 | 完成 |
| release | release 不开放 devtools | 待验证 |

每个“待验证”项目必须在 Windows Tauri 实机验收后更新为 `通过` 或 `阻塞`。
