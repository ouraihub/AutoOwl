# 音乐桌面应用详细设计

## 1. 文档目的和状态

本文档描述 AutoOwl 使用 Svelte 5 + TypeScript + Tauri 2 + Rust 实现的业务行为、模块、DTO 和验收约束。

标记说明：

- **已确认**：可由源码、fixture 或测试直接确认。
- **需运行时验证**：需要真实平台、浏览器或打包环境验证，详细设计不得伪造为已验证。

## 2. 系统边界

AutoOwl 是一个 Windows 优先的 Tauri 桌面应用，逻辑上分为两个子系统，物理上共享一个 Tauri 应用、一个 Rust core 和一个 SQLite 数据库。

```text
AutoOwl
├── 使用子系统
│   ├── 多平台搜索、歌单、专辑
│   ├── 播放器、播放历史、队列
│   ├── 单曲/批量下载和下载记录
│   ├── 本地音乐和本地歌单
│   └── 歌词、封面、音质、换源
└── 管理子系统
    ├── 系统设置、下载目录、文件名模板
    ├── Cookie、登录状态和扫码登录
    ├── FFmpeg/ffprobe、日志和诊断
    └── 功能开关、更新和关于
```

应用只读写自己的应用数据目录，不读取、不修改其它程序的数据库、配置或下载目录。

## 3. 音乐源适配器设计

### 3.1 平台范围

应用支持 12 个远程音源：网易云、QQ、酷狗、酷我、咪咕、Bilibili、汽水、JOOX、千千、Apple Music、Jamendo、5sing。`SourceRegistry` 按 source 分发搜索、歌单、专辑、播放资源和扫码登录；每个平台在 [平台能力矩阵](平台能力矩阵.md) 登记：歌曲搜索、歌单搜索/详情、专辑搜索/详情、链接解析、播放资源、歌词、封面、Range、Cookie、扫码登录和错误降级。

平台的最终运行状态分为：

```text
implemented  已完成 Rust 适配并通过 fixture
verified     已在真实环境验证
degraded     能力存在但当前平台接口不可用
unsupported  平台不提供对应能力
```

### 3.2 Rust 接口

`SourceRegistry` 根据 source 选择平台 adapter，adapter 未实现的能力返回不支持错误。

目标模块：`src-tauri/src/domain/source.rs`、`application/source_use_case.rs`、`infrastructure/sources/<source>.rs`。

```rust
#[async_trait]
pub trait MusicSource: Send + Sync {
    fn id(&self) -> SourceId;
    fn capabilities(&self) -> SourceCapabilities;
    async fn search_songs(&self, query: SearchQuery) -> Result<SearchResult, SourceError>;
    async fn search_playlists(&self, query: CollectionQuery) -> Result<Vec<Playlist>, SourceError>;
    async fn search_albums(&self, query: CollectionQuery) -> Result<Vec<Album>, SourceError>;
    async fn playlist_detail(&self, id: &str) -> Result<CollectionDetail, SourceError>;
    async fn album_detail(&self, id: &str) -> Result<CollectionDetail, SourceError>;
    async fn resolve_song(&self, song: SongRef) -> Result<PlayableResource, SourceError>;
    async fn lyrics(&self, song: SongRef) -> Result<Option<Lyrics>, SourceError>;
    async fn cover(&self, song: SongRef) -> Result<Option<CoverResource>, SourceError>;
    async fn parse_link(&self, link: &str) -> Result<ParsedCollection, SourceError>;
}
```

TypeScript DTO：`src/lib/domain/music.ts`。

```ts
export type SongRef = { source: string; scope: string; siteId: string };
export type Artist = { id?: string; name: string };
export type Song = {
  ref: SongRef;
  title: string;
  artists: Artist[];
  album?: { id?: string; name: string; source?: string };
  durationMs?: number;
  cover?: CoverResource;
  extra?: Record<string, string>;
};
export type SourceCapabilities = {
  songSearch: boolean;
  playlistSearch: boolean;
  albumSearch: boolean;
  playlistDetail: boolean;
  albumDetail: boolean;
  lyrics: boolean;
  cover: boolean;
  qrLogin: boolean;
  qualities: string[];
};
```

Tauri command/event：`search_songs`、`search_playlists`、`search_albums`、`get_collection_detail`、`resolve_playback`、`get_lyrics`、`get_cover`、`parse_collection_link`；source capability 变化通过 `source:status` 事件或查询命令返回。

验收：为每个平台建立固定 JSON fixture；对每个 `implemented` 能力执行 Rust adapter contract test，验证 source、siteId、标题、歌手、时长、错误码和空结果行为。真实网站验证单独标记为 `verified`，不作为唯一 CI 依赖。

## 4. 数据模型和 DTO

### 4.1 歌曲、歌单、专辑

远程内容以 `id + source` 识别，本地内容使用 `source = local`；歌单和专辑通过 content type 区分。

目标模块：`domain/music`、`domain/collection`，前端 `src/lib/domain`。

```ts

  creator?: string;
  coverUrl?: string;
  trackCount?: number;
  link?: string;
  extra?: Record<string, string>;
};
export type CollectionDetail = {
  collection: Collection;
  songs: Song[];
  total: number;
  page: number;
```

Tauri command：`search_collections`、`get_collection_detail`、`import_collection`、`delete_collection`、`add_song_to_collection`、`remove_song_from_collection`、`batch_add_songs_to_collection`。

验收：验证 import/delete/batch 行为；远程歌单和本地歌单不能混淆，歌曲关联必须同时使用 collection id、song id 和 source。

### 4.2 设置

字段包括：`embedDownload`、`downloadToLocal`、`downloadDir`、`downloadFilenameTemplate`、`disableFloatingLyrics`、`webPageSize`、`cliPageSize`、`downloadConcurrency`、`autoCheckUpdate`、`autoSwitchInvalidSources`、`autoCacheOnPlay`、更新代理和视频相关开关。

Tauri command：`get_settings`、`update_settings`、`reset_settings`、`choose_download_directory`。验收：默认值、空路径、空模板、并发范围和保存后重新读取必须覆盖测试。

## 5. 下载详细设计

### 5.1 行为

支持文件名模板、资源 URL、扩展名、下载记录、去重、下载预检和批量下载；模板变量包括 `{name}`、`{artist}`、`{album}`、`{source}`、`{id}`、`{ext}`，路径穿越和非法路径段会被清理。

### 5.2 Rust 模块和状态机

目标模块：`domain/download`、`application/download_use_case.rs`、`infrastructure/download/http_downloader.rs`、`infrastructure/media_tools`。

```text
queued -> resolving -> downloading -> processing -> completed
   |          |             |             |
   +------> cancelled <------+-------------+
              ^
        cancel_requested

queued/resolving/downloading/processing/failed -> retry
```

`DownloadTask` 至少包含：`id`、`songRef`、`title`、`artist`、`source`、`targetPath`、`state`、`progress`、`downloadedBytes`、`totalBytes`、`speedBytesPerSecond`、`error`、`createdAt`、`updatedAt`。

Rust trait：

```rust
trait DownloadService {
    async fn create(&self, request: DownloadRequest) -> Result<DownloadTask, AppError>;
    async fn cancel(&self, task_id: TaskId) -> Result<(), AppError>;
    async fn retry(&self, task_id: TaskId) -> Result<DownloadTask, AppError>;
    async fn get(&self, task_id: TaskId) -> Result<DownloadTask, AppError>;
    async fn list(&self, filter: DownloadFilter) -> Result<Vec<DownloadTask>, AppError>;
}
```

Tauri command/event：`create_download`、`cancel_download`、`retry_download`、`get_download_task`、`list_download_tasks`；事件 `download:changed`。command 立即返回任务 DTO，长任务在 Tokio 后台运行，取消使用 cancellation token。

验收：覆盖模板渲染、非法路径、重复目标、资源失败、取消、重试、临时文件清理和记录分页。

## 6. 播放器详细设计

### 6.1 行为

全局播放器，歌曲列表可以加入队列，支持播放/暂停、上一首/下一首、进度、音量、播放模式、歌词、播放历史和媒体键。

### 6.2 状态和规则

```text
PlayerState = idle | loading | playing | paused | ended | failed
PlayMode = sequential | random | singleLoop
```

Rust `PlayerService` 管理事实状态，前端 `playerStore` 只维护显示状态。播放失败必须携带 source、songRef 和错误码；允许 application 层触发重新解析或换源。系统媒体键转换为 `player:command`，播放状态变化推送 `player:changed`。

Tauri command/event：`player_load`、`player_play`、`player_pause`、`player_seek`、`player_set_volume`、`player_set_mode`、`player_next`、`player_previous`、`player_get_state`；事件 `player:changed`、`player:position`、`player:error`。

验收：覆盖队列顺序、随机、单曲循环、结束自动下一首、失败提示、媒体键和页面切换后状态恢复。

## 7. 本地音乐详细设计

行为包括扫描下载目录、分页、快照缓存、后台刷新、元数据缓存、封面/歌词读取、上传、删除、重复检测、索引搜索和加入本地歌单。

目标模块：`domain/local_music`、`application/local_music_use_case.rs`、`infrastructure/filesystem`、`infrastructure/media_tools`、`infrastructure/storage/local_music_repository.rs`。

```rust
trait LocalMusicRepository {
    async fn list(&self, page: PageRequest) -> Result<Page<LocalTrack>, AppError>;
    async fn upload(&self, input: UploadInput) -> Result<LocalTrack, AppError>;
    async fn delete(&self, track_id: &str) -> Result<(), AppError>;
    async fn find_duplicates(&self) -> Result<Vec<DuplicateGroup>, AppError>;
    async fn search(&self, query: &str) -> Result<Vec<LocalTrack>, AppError>;
}
```

Tauri command：`list_local_music`、`upload_local_music`、`delete_local_music`、`find_local_duplicates`、`search_local_music`、`refresh_local_music`、`add_local_tracks_to_collection`；事件 `local_music:scan_progress`、`local_music:changed`。

验收：使用临时目录验证分页、快照缓存、后台刷新、ffprobe 缺失降级、内嵌封面、同名歌词、上传重名、硬删除、重复组和索引清理。

## 8. 认证和管理子系统

### 8.1 平台 Cookie

按 source 保存 Cookie，前端只能查看脱敏状态并提交更新。

目标模块：`domain/auth`、`infrastructure/credentials/credential_store.rs`。Cookie 原文不得进入前端 store、普通日志或错误 details；SQLite 中的 `credentials.encrypted_value` 由 `infrastructure/secret.rs` 以 DPAPI 加密，旧明文行首次加载时自动重新加密。

### 8.2 扫码登录

Tauri command：`get_auth_status`、`save_cookie`、`clear_cookie`、`start_qr_login`、`poll_qr_login`；事件 `auth:changed`、`auth:qr_status`。平台适配器返回 `pending`、`scanned`、`confirmed`、`expired`、`failed`，不得把平台原始响应直接返回前端。

### 8.3 系统管理

桌面首发不做多人后台，但管理命令独立分组：`get_settings`、`update_settings`、`get_media_tool_status`、`get_diagnostics`、`check_update`。管理命令必须单独校验路径、Cookie、外部链接和进程能力。

## 9. SQLite 设计

数据库位于应用自己的数据目录，迁移版本独立管理。基础表：

```sql
CREATE TABLE schema_migrations(version INTEGER PRIMARY KEY, applied_at TEXT NOT NULL);
CREATE TABLE app_settings(key TEXT PRIMARY KEY, value_json TEXT NOT NULL, updated_at TEXT NOT NULL);
CREATE TABLE credentials(source TEXT PRIMARY KEY, encrypted_value BLOB NOT NULL, updated_at TEXT NOT NULL);
CREATE TABLE download_tasks(
  id TEXT PRIMARY KEY, source TEXT NOT NULL, scope TEXT NOT NULL, site_id TEXT NOT NULL,
  title TEXT NOT NULL, artist TEXT, target_path TEXT NOT NULL, state TEXT NOT NULL,
  progress REAL NOT NULL DEFAULT 0, error_code TEXT, created_at TEXT NOT NULL, updated_at TEXT NOT NULL
);
CREATE INDEX idx_download_tasks_state ON download_tasks(state);
CREATE INDEX idx_download_tasks_created_at ON download_tasks(created_at DESC);
```

后续本地音乐和歌单表必须在详细迁移设计中增加唯一约束：远程歌曲使用 `source + scope + site_id`，歌单歌曲关联使用 `collection_id + song_id + source`。每次迁移在事务中执行，失败回滚；不得把 schema 迁移和业务启动混在不可恢复的初始化流程中。

## 10. Tauri capability 和前端边界

首发 capability 只开放窗口、事件、dialog、限定下载目录的 fs、通知和必要外部链接。禁止前端任意读写路径、执行任意命令或直接访问凭据存储。FFmpeg/ffprobe 只能由 Rust infrastructure adapter 以固定参数启动。

前端服务分组：

```text
src/lib/services/user/
├── search-service.ts
├── player-service.ts
├── download-service.ts
├── collection-service.ts
└── local-music-service.ts

src/lib/services/admin/
├── settings-service.ts
├── auth-service.ts
├── media-tool-service.ts
└── diagnostics-service.ts
```

组件不得直接调用 Tauri `invoke`；所有 command 名称、输入和返回值由 typed service 封装。

## 12. 错误、日志和可观测性

Rust 使用 `tracing`/`tracing-subscriber`；每个搜索、下载、扫描、扫码会话都有 `operationId` 或 `taskId`。对外错误结构：

```ts
type AppError = {
  code: string;
  message: string;
  retryable: boolean;
  operationId: string;
};
```

首发错误码包括：`INVALID_ARGUMENT`、`SOURCE_UNAVAILABLE`、`SOURCE_AUTH_REQUIRED`、`RESOURCE_NOT_FOUND`、`RESOURCE_EXPIRED`、`NETWORK_TIMEOUT`、`RATE_LIMITED`、`DOWNLOAD_CANCELLED`、`DOWNLOAD_FAILED`、`FILE_CONFLICT`、`FFMPEG_NOT_FOUND`、`PERMISSION_DENIED`、`INTERNAL_ERROR`。Cookie、密码、完整敏感 URL 和用户文件内容禁止写入日志。

## 13. 测试和 Definition of Done

每个平台 source adapter 使用 fixture/contract test；domain 测状态机和错误映射；application 测用例、重试、取消和事务；infrastructure 使用临时目录、测试数据库和 fake HTTP/FFmpeg；interface 测 command 参数、DTO 和 event；前端使用 Vitest 测 service、store、组件交互和页面状态。

每个功能完成必须满足：

1. 有行为说明（设计文档或代码注释）。
2. 有 Rust 模块、trait、DTO、Tauri command/event 和前端 typed service。
3. 有成功、失败、取消或重试路径。
4. 有 fixture、单元测试或集成测试。
5. 有结构化日志和稳定错误码。
6. 通过 `pnpm check`、`pnpm test`、`pnpm build`、`cargo fmt --check`、`cargo clippy --all-targets --all-features -- -D warnings` 和 `cargo test`。
7. 在 Windows Tauri 开发或打包环境完成真实验收。

各平台能力和验证状态见 [平台能力矩阵](平台能力矩阵.md)，匿名实测结果见 [音源与已知问题](音源与已知问题.md)。“静态可见”表示代码存在对应分发入口，不代表当前真实网站仍然可用。

## 16. 完整 DTO、Command 和 Event 契约

### 16.1 DTO

跨 Tauri 边界使用 camelCase JSON，Rust 内部字段使用 snake_case 并显式序列化转换。

```ts
export type PageInput = { page: number; pageSize: number };
export type SearchSongsInput = PageInput & {
  query: string;
  searchType: "song" | "playlist" | "album";
  sources: string[];
};
export type SearchResultDto = { items: Song[] | Collection[]; total?: number; page: number; pageSize: number; sources: SourceStatus[] };
export type PlayableResourceDto = { song: SongRef; url: string; quality: string; durationMs?: number; expiresAt?: string };
export type DownloadTaskDto = {
  id: string; song: Song; targetPath: string;
  state: "queued" | "resolving" | "downloading" | "processing" | "completed" | "failed" | "cancelRequested" | "cancelled";
  progress: number; downloadedBytes: number; totalBytes?: number; speedBytesPerSecond?: number;
  error?: AppError; createdAt: string; updatedAt: string;
};
export type AuthStatus = { source: string; configured: boolean; qrSupported: boolean; displayName?: string };
export type LocalTrack = Song & { path: string; fileSize: number; modifiedAt: string; bitrate?: number; format: string };
```

## 17. SQLite 完整设计补充

```sql
CREATE TABLE collections (
  id TEXT PRIMARY KEY, kind TEXT NOT NULL, content_type TEXT NOT NULL,
  source TEXT NOT NULL, external_id TEXT, name TEXT NOT NULL,
  description TEXT, creator TEXT, cover_url TEXT, link TEXT,
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL
);
CREATE UNIQUE INDEX idx_collections_external ON collections(source, external_id, content_type);
CREATE TABLE collection_songs (
  collection_id TEXT NOT NULL, song_id TEXT NOT NULL, source TEXT NOT NULL,
  position INTEGER NOT NULL, song_json TEXT NOT NULL, created_at TEXT NOT NULL,
  PRIMARY KEY(collection_id, song_id, source),
  FOREIGN KEY(collection_id) REFERENCES collections(id) ON DELETE CASCADE
);
CREATE INDEX idx_collection_songs_position ON collection_songs(collection_id, position);
CREATE TABLE local_music_tracks (
  id TEXT PRIMARY KEY, path TEXT NOT NULL UNIQUE, fingerprint TEXT,
  title TEXT NOT NULL, artist TEXT, album TEXT, format TEXT NOT NULL,
  file_size INTEGER NOT NULL, modified_at TEXT NOT NULL,
  metadata_json TEXT NOT NULL, indexed_at TEXT NOT NULL
);
CREATE INDEX idx_local_music_title_artist ON local_music_tracks(title, artist);
CREATE TABLE playback_history (
  id INTEGER PRIMARY KEY AUTOINCREMENT, song_json TEXT NOT NULL, played_at TEXT NOT NULL
);
CREATE INDEX idx_playback_history_played_at ON playback_history(played_at DESC);
CREATE TABLE download_dedup (
  source TEXT NOT NULL, scope TEXT NOT NULL, site_id TEXT NOT NULL,
  target_path TEXT NOT NULL, created_at TEXT NOT NULL,
  PRIMARY KEY(source, scope, site_id, target_path)
);
```

迁移规则：每个版本一个事务；失败整体回滚；删除歌单级联删除关联但不删除远程歌曲事实；本地音乐删除同时删除文件、索引和本地 source 关联；下载历史清理不得清除 dedup 记录。

## 18. 播放器队列和模式规则

| 场景 | 规则 | 状态 |
|---|---|---|
| 播放 | 当前歌曲进入 loading，资源成功后进入 playing | 已确认结构，运行时验证时序 |
| 暂停 | 保留当前索引和进度 | 已确认 |
| 结束 | sequential 下一首，singleLoop 重播，random 选择未播放项 | 需运行时验证 |
| 上一首 | 播放超过 3 秒回到当前开头，否则上一首 | 需运行时验证 |
| 播放失败 | failed，保留错误码，允许重试或换源 | 设计约束 |
| 历史 | 有效播放后写入 history | 需运行时验证 |
| 自动缓存 | `autoCacheOnPlay` 开启时创建缓存任务 | 设计约束 |
